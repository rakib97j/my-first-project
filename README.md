KV Knowledge Vault

Jan 2026 – Jan 2026

I built Knowledge Vault, a web project using HTML and CSS, as part of my web development journey. It is a platform designed to help users organize their notes, links, and learning summaries in a structured way. The focus is on structured thinking, not just note-taking, allowing users to connect ideas and turn learning into long-term knowledge.

Key Features:

Clean web design

Private space to store notes and links

Focus on structured learning and idea organization

Simple, user-friendly interface

This project helped me practice HTML, CSS while building a real-world web application.

 HTML and Cascading Style Sheets (CSS)
